# Проект интернет-магазина

## Описание:

Проект интернет-магазина

## Установка:

1. Клонируйте репозиторий:
```
git@github.com:MariyaKuznetsova/pythonproject10.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. В интернет-магазине приложения, вы можете просматривать, добавлять, удалять продукты, если у вы авторизованный пользователь.
2. Проверка пользователя внесена в приложение.
3. Пользователь проходит проверку почты, чтобы полностью авторизоваться в приложении.
4. Также в приложение есть группы, у которых есть определенные права доступа.
5. Добавлены права доступа для владельцев продуктов, которые могут удалять и редактировать карточку продукта.
6. Остальные пользователи могут только просматривать и не вносить никаких изменений в приложение.
